# Barril de Incertezas: O Impacto do Risco Geopolítico nos Mercados Petrolíferos (2015–2026)

Desenvolvido em Python e Google Colab, este projeto investiga a relação entre o risco geopolítico, os preços do petróleo e as principais empresas do setor energético. A análise combina técnicas econométricas, modelação de volatilidade e métodos de machine learning para avaliar o comportamento do mercado e prever movimentos futuros dos preços.

## Metodologias Utilizadas

- Análise de Correlação
- Regressão Linear
- Modelo GARCH(1,1)
- Prophet
- XGBoost

## Principais Resultados

- A correlação entre GPR e Brent passou de -0,27 para +0,41.
- O prémio de risco geopolítico foi estimado em US$ 0,173 por barril para cada ponto adicional do índice GPR.
- A persistência da volatilidade atingiu 97,1% (α + β = 0,971).
- O modelo XGBoost alcançou 97,79% de precisão na previsão do Brent.

## Tecnologias

Python, Pandas, NumPy, Plotly, Matplotlib, Statsmodels, Prophet, XGBoost, Econometria e Machine Learning.
